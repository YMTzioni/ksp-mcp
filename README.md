# KSP — חיפוש ומבצעים

## גלישה לאתר

**https://ymtzioni.github.io/ksp-mcp/**

פתחו את הקישור בדפדפן (מחשב או נייד). אין התקנה, אין הרצה מקומית — הכל רץ אונליין.

## מה אפשר לעשות

| תכונה | תיאור |
|--------|--------|
| **חיפוש** | חיפוש מוצרים, סינון, מיון, כרטיסים או טבלה |
| **יניב** | סריקת מבצעים (מציאון, חיסול מלאי, outlet ועוד) |
| **תחקור** | ניתוח מחירים, חיסכון, מוצרים דומים |
| **השוואה** | השוואה בין עד 5 מוצרים |
| **ייצוא** | הורדת תוצאות יניב כ-CSV |

## שימוש קצר

1. היכנסו לקישור למעלה.
2. ודאו שמופיע **«מחובר ל-KSP»** בראש הדף.
3. חפשו מוצר או לחצו **התחל סריקה** בלשונית יניב.

> סריקת יניב עשויה לקחת דקה–שתיים — הנתונים נטענים ישירות מ-KSP.
